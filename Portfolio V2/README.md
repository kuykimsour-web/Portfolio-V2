# Kimsour Kuy - Portfolio Website

A modern, responsive, and professional portfolio website built using **HTML5, CSS3, and Vanilla JavaScript**. This portfolio showcases my background, technical skills, projects, and contact information as a **First-Year Bachelor of Data Science and Engineering student** at the **Royal University of Phnom Penh (RUPP)**.

The website features a clean, premium design with support for **Light/Dark Mode**, smooth animations, and a fully responsive layout, providing an excellent user experience across all devices.
